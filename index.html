Baixa de Entradas
Casa os débitos do extrato Sicoob (carregado acima) com o Contas a Pagar por Fornecedor (carregado acima) — pelo CNPJ/CPF que já vem embutido na maioria das linhas do extrato, resolvido pelo cadastro de CNPJ compartilhado do escritório (mesmo das outras ferramentas — sincroniza sozinho, sem upload). Quando um pagamento cobre mais de uma nota do mesmo fornecedor, soma automaticamente (busca exata, nunca aproxima). Pro que sobrar sem match (pago via intermediário, ou direto pelo Caixa — nunca aparece no extrato bancário), busca o Nº do documento no Livro Diário CaixaW (se anexado acima) — essas linhas ficam marcadas "PAGO VIA CAIXA" pra você conferir a conta de crédito certa no Domínio. Gera baixa_ent.txt pro Domínio.
Cadastro — Lançamentos Padrões
De-para de palavra-chave (do histórico do extrato) → contas de débito/crédito. Deixe Débito ou Crédito em branco pra usar só a conta banco (10) nesse lado, com o outro em branco pra completar à mão. Marque "Ignorar" pra excluir do lançamento. Clique em "+ Novo padrão" pra adicionar mais regras.
Pra um histórico calculado a partir do texto original da linha (ex. incluir o CNPJ/nome que vêm embutidos na descrição), use histFn:"nomeDaFuncao" em vez de hist — a função precisa existir no código, dentro de HIST_FUNCOES (peça pro Claude adicionar uma nova se precisar).
Cadastro — Repasses ACC (Asilo São Vicente de Paulo / Hospital São José)
Recebimentos via Pix pro CPF de cada funcionário — sempre D263 C10 (Asilo) ou D268 C10 (Hospital), histórico "PAGAMENTO REF. REPASSE ACC {ASILO/HOSPITAL} ... PARC. N PARA {NOME}". A parcela é POR PESSOA (uma pode estar mais adiantada que outra) e incrementa sozinha a cada mês processado com sucesso — corrija manualmente "Última Parcela" se pular um mês ou reprocessar. "Grupo" define qual convenção usar (asilo ou hospital). Clique em "+ Nova pessoa" pra adicionar alguém novo confirmado pelo usuário.
